# 已有资料处理

## 轻量盘点

已有资料用于理解用户的真实知识工作，不把文件数量或搬运规模当作成果。先运行：

```text
python3 scripts/runtime_tool.py inventory --source <资料绝对路径> --pretty
```

盘点只读取路径、名称、类型、大小、时间、链接方向和安全分类。只有结构判断、关系确认或代表性任务确实需要时，才依次读取元数据、标题、目录、必要片段和正文。

盘点失败时报告具体路径和错误，保持零写入。不得跟随项目外链接继续读取，也不得读取疑似密钥或凭证。缓存、依赖、构建产物和临时文件默认排除。

## 资料判断

根据资料在知识工作中的职责判断处理方式：

- 可直接复用的知识文档：保留内容，按确认后的职责归类或建立链接；
- 仍在持续维护的外部资料：保留原位置并记录来源；
- 代码、原型、设计源文件和大型素材：作为完整资产引用，不拆散；
- 版本冲突、归属不明或关系不足的资料：保留并进入待处理；
- 噪声或敏感内容：排除并说明原因，不复制正文。

扩展名只辅助判断，不能决定业务归属。不为追求统一而批量改写历史文档，不删除疑似重复内容，不把当前判断不清的资料强行归类。

## 对已有内容的变更门

需要批量移动、重命名、重分类、覆盖或更新链接时，先给出带稳定 ID 的清单：

```text
C1｜移动｜原路径 → 目标路径｜归入已确认的知识职责
C2｜更新链接｜文件路径｜指向新的目标位置
```

同时明确不涉及的动作，尤其是删除、覆盖和跨出目标目录。只执行用户确认的 ID；范围、路径或影响发生变化时重新说明并确认。不得永久删除唯一原件。
