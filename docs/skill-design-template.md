# Skill Design Template

Use this template before creating a new skill.

## Skill Name

`lowercase-hyphen-name`

## Target User

Who will use this skill?

## Trigger Scenario

When should the AI use this skill?

Good trigger descriptions include:

- User intent.
- Input materials.
- Expected output.
- Boundary conditions.

## User Input

List the likely input:

- Rough idea.
- Screenshot.
- Meeting notes.
- Existing document.
- Product context.
- Business constraints.

## Expected Output

Define the result:

- PRD.
- Brief.
- Review comments.
- Decision memo.
- Task breakdown.
- GitHub-ready files.

## Workflow

Describe the steps the AI should follow:

1. Read relevant context.
2. Identify missing information.
3. Ask only necessary clarifying questions.
4. Produce the artifact.
5. Call out assumptions and open questions.

## Guardrails

State what the skill should avoid:

- Do not invent facts.
- Do not save secrets.
- Do not turn every note into a full PRD.
- Do not over-structure simple ideas.

## Example Prompt

Write one realistic user prompt that should trigger the skill.

## Example Output

Write a short example of the expected result.
